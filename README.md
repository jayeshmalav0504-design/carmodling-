# THE CAR MODLING — 3D & 4D Interactive Car Design Studio

A high-performance, single-page 3D/4D automotive design studio built with **Three.js (r128)**, **Tailwind CSS**, and an intelligent **Gemini AI Design Mentor** co-pilot.

## Features

- **6 Distinct 3D Vehicle Architectures**:
  - 🏎️ **GT Supercar**: Classic track coupe with active aerodynamic rear wing.
  - 🏁 **Formula 1**: Open-wheel monocoque, needle nose, wide front F1 wing, halo safety bar, airbox snorkel, shark fin, and bi-plane rear wing.
  - ⚡ **Hypercar Wedge**: Mid-engine wedge silhouette with roof air scoop, aggressive side intake scoops, and rear racing diffuser.
  - 🚙 **Safari SUV**: Rugged 4x4 with lifted suspension, safari roof rack with 4 LED spotlights, and rear-mounted spare tire.
  - 🔥 **American Muscle**: Bulging shaker hood scoop, squared aggressive front grille, and fastback ducktail.
  - ✨ **Speedster Spyder**: Open-air roadster with frameless low-profile wind deflector and dual aerodynamic streamliner cowls.

- **Real-Time Natural Language Gemini AI Co-Pilot**:
  - The 3D car model directly and instantly sculpts in real-time based on natural language commands (e.g., *"make it yellow with black rims"*, *"add big GT wing"*, *"slam suspension with drift camber"*, *"Red Bull F1 spec"*).
  - Built-in zero-latency **Gemini Smart Design Engine** enabled by default (no API keys required).
  - Optional support for personal Google AI Studio API keys.
  - 1-Click **Undo AI Changes** feature.

- **Cinematic Red Bull F1 Video Intro**:
  - Seamless animated video overlay with instant "⚡ ENTER 3D STUDIO" entrance and sound controls.

- **Interactive 4D Wind Tunnel & Audio Revving**:
  - Real-time aerodynamic wind streamlines at varying test speeds.
  - Web Audio API procedural exhaust acoustics with throttle revving.

- **Designer Garage & Authentication**:
  - Local accounts, password hashing, and persistent multi-car garage saving.
  - 3D `.GLB` model export and high-resolution PNG rendering.

## Quick Start

Open `index.html` in any modern web browser (Google Chrome, Edge, Brave, Firefox).
